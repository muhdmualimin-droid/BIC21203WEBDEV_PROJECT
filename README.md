Improvements Made to Kenyalang Rail PIS:
Code Restructuring – Separated HTML, CSS, JavaScript, and PHP.
No Bootstrap – Maintained custom CSS without frontend frameworks.
API Simplification – Replaced the external KTMB API with staff-managed MySQL updates.
Page Optimization – Reduced the website from 15 to 14 pages.
UI/UX Redesign – Introduced the modern Frosted Transit (Semi-Glass) theme.
New Branding – Added the Kenyalang hornbill logo and favicon.
Visual Improvements – Replaced placeholder graphics with realistic railway images.
Routes Map – Improved railway route visualization and station labels.
Digital Departure Board – Enhanced train information display with 15-second auto-refresh.
Smooth Loading – Added skeleton loading, fade-in effects, and flicker reduction.
Responsive Design – Improved desktop, tablet, and mobile layouts.
Admin CRUD Interface – Refined forms, validation feedback, and management controls.
Layout Optimization – Improved login page spacing and footer positioning.
Role-Based Access Control – Implemented different permissions for Admin and Staff.
