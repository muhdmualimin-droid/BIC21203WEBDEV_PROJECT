## Improvements & Enhancements

The following improvements were made to the original Kenyalang Rail PIS project:

- **Code Restructuring:** Separated HTML, CSS, JavaScript, and PHP for better maintainability.
- **No Bootstrap:** Used custom CSS without frontend frameworks.
- **API Simplification:** Replaced the external KTMB API with staff-managed MySQL updates.
- **Page Optimization:** Organized the website into 14 pages.
- **UI/UX Redesign:** Introduced the Frosted Transit (Semi-Glass) theme.
- **New Branding:** Added the Kenyalang hornbill logo and favicon.
- **Visual Improvements:** Replaced placeholders with realistic railway imagery.
- **Routes Map:** Improved route visualization and station labels.
- **Digital Departure Board:** Enhanced the display with 15-second auto-refresh.
- **Smooth Loading:** Added skeleton loading, fade-in effects, and flicker reduction.
- **Responsive Design:** Improved desktop, tablet, and mobile layouts.
- **Admin CRUD:** Refined management forms and validation feedback.
- **Layout Optimization:** Improved login page spacing and footer positioning.
- **Role-Based Access Control:** Applied different permissions for Admin and Staff.
