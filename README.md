## Improvements & Enhancements

The following improvements were made to the original Belang Rail PIS project:

- **Code Restructuring:** Separated HTML, CSS, JavaScript, and PHP for better maintainability. — **23 Nov 2026**
- **No Bootstrap:** Used custom CSS without frontend frameworks. — **23 Nov 2026**
- **API Simplification:** Replaced the external KTMB API with staff-managed MySQL updates. — **23 Nov 2026**
- **Page Optimization:** Organized the website into 14 pages. — **23 Nov 2026**
- **UI/UX Redesign:** Introduced the Frosted Transit (Semi-Glass) theme. — **23 Nov 2026**
- **New Branding:** Rebranded Kenyalang Rail PIS to Belang Rail PIS with a tiger-inspired logo and favicon. — **27 Nov 2026**
- **Color Palette:** Updated the website with a premium Navy, Blue-Grey, and Beige theme. — **27 Nov 2026**
- **Typography Refinement:** Improved brand typography and navigation text consistency. — **27 Nov 2026**
- **Visual Improvements:** Replaced placeholders with realistic railway imagery. — **23 Nov 2026**
- **Routes Map:** Improved route visualization and station labels. — **24 Nov 2026**
- **Digital Departure Board:** Enhanced the display with 15-second auto-refresh. — **24 Nov 2026**
- **Smooth Loading:** Added skeleton loading, fade-in effects, and flicker reduction. — **23 Nov 2026**
- **Responsive Design:** Improved desktop, tablet, and mobile layouts. — **24 Nov 2026**
- **Admin CRUD:** Refined management forms and validation feedback. — **23 Nov 2026**
- **Layout Optimization:** Improved login page spacing and footer positioning. — **24 Nov 2026**
- **Role-Based Access Control:** Applied different permissions for Admin and Staff. — **25 Nov 2026**
- **Welcome Audio Announcement:** Added a railway-style welcome announcement with a speaker control and browser-permitted autoplay. — **27 Nov 2026**
- **Persistent Admin Session:** Improved navigation between Passenger Pages and Operations without unnecessary re-login. — **27 Nov 2026**
- **Session-Aware Navigation:** Redirects authenticated Admin and Staff users directly to the Dashboard. — **27 Nov 2026**
- **Password Visibility Toggle:** Added an eye icon to show or hide passwords on the Login Page. — **27 Nov 2026**
- **Login Bug Fix:** Resolved the JavaScript error `startAdmin is not defined` caused by a duplicate login form handler. — **27 Nov 2026**
- **Login UI Improvement:** Refined the password field layout, eye icon positioning, and accessibility. — **27 Nov 2026**
